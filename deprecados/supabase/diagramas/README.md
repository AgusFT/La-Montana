## Objetivo

Esta carpeta conserva los diagramas v2 de arquitectura, componentes y despliegue
asociados a la etapa en la que Supabase era considerado backend y fuente de
verdad del proyecto La Montana.

Los archivos quedan preservados como evidencia historica. No representan la
arquitectura vigente.
