La Montaña Demo para Windows · YG Soluciones

Al instalar la Demo se copian el asistente y los componentes que necesita
para preparar la aplicación sin conexión. En la carpeta app/paquete están
AVISOS-TERCEROS.zip, con textos originales de licencia y atribución, y
release.properties, con los nombres, versiones y sumas SHA-256 de la carga.

Firefox @FIREFOX@ para Windows x64 (es-AR)
Se distribuye una copia intacta del instalador de Mozilla. Podés consultar
las licencias en about:license dentro de Firefox y en AVISOS-TERCEROS.zip.
Código fuente correspondiente a esta versión:
https://archive.mozilla.org/pub/firefox/releases/@FIREFOX@/source/firefox-@FIREFOX@.source.tar.xz

Eclipse Temurin / OpenJDK 17
El runtime de Windows y el del servicio web incluyen sus textos en legal/.
OpenJDK usa GPLv2 con Classpath Exception y licencias específicas para
componentes individuales. Las versiones figuran en el inventario adjunto.
https://github.com/adoptium/temurin17-binaries/releases

Windows Subsystem for Linux, Ubuntu y Docker Engine
El paquete MSI oficial de WSL conserva NOTICE.txt con las indicaciones
de Microsoft para obtener las fuentes de sus componentes. La distribución
Ubuntu y los paquetes .deb incorporan software bajo distintas licencias.
AVISOS-TERCEROS.zip identifica los paquetes, sus versiones y los avisos
recuperados. Incluye materiales de Docker Engine, CLI, Buildx, Compose y
containerd. El archivo docker-descargas.properties identifica cada .deb.

Servicios de la aplicación
La aplicación utiliza PostgreSQL, Mailpit, ClamAV, Node.js, Next.js,
React, PDF.js y bibliotecas Java, entre otros componentes. Las bases de
firmas ClamAV conservan su archivo COPYING. En AVISOS-TERCEROS.zip se
pueden consultar los inventarios, las atribuciones y las licencias de
terceros que acompañan esta edición.
